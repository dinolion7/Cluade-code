## 제목
"파리가 부른다" 23세 안유진, 공항서 난리 난 압도적 미모 근황 (+컴백 스포까지)
- 구조: **"인용구" + 나이 + 인물 + 사건(공항서 난리) + 근황 + (+덤 정보)**
- 같은 카테고리·인기글 제목이 전부 따옴표 인용으로 시작: "장수 커플인 줄 알았는데…" 구교환♥이옥섭… / "누구 닮았나요?" 김해준♥김승혜… / "언제나 우리가 함께"…아이유가 데뷔 18주년에… / "가을야구 잔혹사 끝냈다!" … — 블로그 고유 틀

## 본문 형식
- **가운데 정렬**, 한 줄 15~20자에서 수동 줄바꿈, 2~5줄 덩어리 + 빈 줄
- 소제목 3개: 이모지 + 굵게, 두 줄. ("Paris is calling"… 공항마저 런웨이로 만든 그레이 니트 룩 / 라코스테 2027 S/S 파리 패션위크 참석차 파리 출국! / 이번엔 '걸 히어로'! 아이브, 10월 19일 선공개 컴백 스포일러)
- 사진 7장, 모두 아래에 출처 캡션: "c. 안유진 SNS", "c. 스타쉽엔터테인먼트", "c. 스포츠조선"
- 핵심 단어 굵게(그레이 컬러 브이넥 니트, 10월 19일 등)
- 분량 약 1,000자 추정(본문 글자만)
- 해시태그 약 35개(본문 끝 20여 개 + "+15")

## 흐름
1. 인사 + 떡밥: "요즘 물이 제대로 올랐다고 소문난 아이돌 있죠?" → 이름 공개 → "한눈에 알아볼게요"
2. SNS 사진 + 착장 설명(아이템·색·포즈)
3. 출국 이유(사실: 10월 3일 인천공항, 라코스테 2027 S/S 파리 패션위크) + 나이(2003년생, 만 23세)
4. **두 번째 뉴스를 붙임**: 컴백 일정(10/19 선공개, 10/26 앨범), 콘셉트, 월드투어, 출연 예능
5. 마무리: "재미있게 보셨나요?" + "다음에도 빠르게 돌아올게요" + 인사

## 관찰
- 공항 패션 단신 + 컴백 일정을 **한 글로 묶어** 정보량을 늘림. 제목 괄호 "(+컴백 스포까지)"가 그 덤을 예고
- 사실은 날짜·행사명·앨범명 위주의 확인 가능한 것만, 평가는 "후문이에요", "~했다고 해요" 전달형
- 감탄·이모지 많고 친근한 해요체. "안유진 양" 호칭
- 같은 블로그가 엔터와 스포츠를 같이 함. 엔터 글 공감 2~6, 스포츠 인기글 공감 최대 36 → 이 블로그는 스포츠가 더 잘 됨
- 엔터 발행 간격: 2주 사이 5개 정도(매일 아님)
