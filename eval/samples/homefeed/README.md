## 모바일 카드 형태와 보이는 글자 수 (400px)

- **한 칸 일반 카드**: 블로그명·시간 → 제목 1줄(약 28~30자에서 "…") → 큰 사진(여러 장이면 1/5+) → 공감·댓글.
- **2열 카드**(경제판에 많음): 사진 아래 제목 2줄, 약 25~28자에서 "…". 넓은 카드는 2줄 약 44자.
- **사진 전체형(클립·영상)**: 제목 없이 썸네일 속 큰 글씨가 제목 역할.
- → 확실히 보이는 건 앞 약 25자. 핵심 후킹과 주제어(정책명)는 앞 25자 안에 있어야 한다.

## 추천·분류

- 경제판 "경제 NOW by AiRS" — 네이버 AI 추천(AiRS)이 배치한다.
- 카드 아래 주제 태그(부동산, 저축·금융상품, 실전 투자 전략) — 글이 주제로 분류돼 해당 판에 올라간다. 제목·첫 화면의 구체 명사(정책명·대상·금액)가 분류 단서로 보인다(추정).
- 광고 카드가 많이 섞인다 — 제목·썸네일이 광고보다 눈에 띄어야 한다.

## 제목 패턴 (정책·생활 계열 실제 예)

- 인용·속마음으로 시작(약 3분의 1): "내일부터 출근하지 마세요" 부당해고에도 실업급여 못 받을 수 있어 / "경기도 돈 없다더니..." 산후조리비 끊겼네요 / "여보 이제 혼인신고 하자" 보금자리론 때문에… / "입원·수술 없었다면 보험료 할인"…보험사가 유…
- 놀람·질문형: 국민연금을 68세에 받는다고?! 정년… / 50대 순자산 중위값, 얼마나 모아야 노후준비가… / 이거 발급된거 아직 아니죠?
- 수치 1개 + 상황: 월급 450만원으로 얼마짜리 아파트 살 수 있… / 청약통장 8.2조원 빠졌다... 종합저축 전환… / 강남 70~80대가 받는 국민연금 실제 액수
- 공통: 주제어가 앞 15자 안, 숫자는 대개 1개.

## 썸네일

- 대부분 큰 글씨 2~3줄(어두운 바탕 흰·노랑, 강조 빨강). 사진만 있는 것은 적다.
- 썸네일 글씨가 제목 핵심 10~20자와 같은 문구인 경우가 많다(예: "강남 70~80대가 받는 국민연금 실제 액수", "2026년 부동산 세제 개편안에 따른 주택시장 영향"). 여기에 숫자 1~2개를 붙인다.
- 정책 사례: 썸네일 "여보 이제 혼인신고 하자 / 10월 19일부터 바뀐다"(인물 사진 + 노랑·빨강 강조).

## 주제별 비교 (사용자 경험 + 검색, 2026-10-05)

- 사용자 경험: 엔터·이슈, 스포츠, 경제가 3대장, 그다음 뷰티패션. 건강·자동차·IT·교육은 약하다.
- 검색: 주제별 홈판 유입을 비교한 공식 자료는 없다. 간접 근거 — 상단 탭에서 IT·자동차는 "카테크" 한 판, 교육은 독립 판 없음 / 네이버 모바일 많이 본 뉴스 비중(이투데이, 예전 자료) 연예 40.7%·사회 24.3%·정치 10.7%·생활 10.0%·경제 2.9%·IT과학 2.1% / 블로거 경험담: 시의성 화제 + 반전·숫자 제목이 홈판에 잘 걸림.
- 정책뉴스·복지로에 주는 의미: 경제판(돈)으로 분류되게 — 지원금·세금·연금·대출·요금처럼 "내 돈이 얼마나 늘거나 줄어드는지"를 제목·첫 화면에 둔다. 건강·교육 정책도 "받는 돈·아끼는 돈" 각도로 잡으면 경제판에 걸릴 가능성(추정).
