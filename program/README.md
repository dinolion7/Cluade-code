## 저장 전 모바일 문단 정리 (Ver10.05)

- 8)탭에 "📱 문단 정리(GPT)" 체크(**기본 꺼짐**)와 기준 글자 수 칸(**기본 150자**, 80~400)이 있다. 두 값 모두 재실행 후에도 유지된다. 켜 두면 "✅ 최종 확정" 때 게시판 판정과 함께 백그라운드로 돈다.
- **기존 문단 구분은 그대로 두고, 기준을 넘는 문단만 나눈다.** 문단을 합치지는 않는다. 각색 결과는 이미 빈 줄로 1~3문장씩 나뉘어 있기 때문이다(샘플 문단 4,000개 기준 중간값 약 100자, 150자 초과 12%).
- 기준을 넘는 문단이 없으면 GPT를 부르지 않는다. 있으면 그 문단들만 묶어 글 1개당 1번 호출한다.
- GPT(`PARA_REFLOW_MODEL`, gpt-4.1-mini)는 문단별 `앞`/`뒤`/`없음`만 JSON으로 답한다. 코드가 원래 문장을 그대로 이어 붙이며 나눈 자리에만 빈 줄을 넣는다. 공백을 뺀 전후 본문이 다르거나 응답이 잘못되면 원본을 쓴다.
- 나누는 자리는 한 문단에 **한 곳**이며, 뽑아낸 문단 기준으로 **첫 문장 뒤(앞)** 또는 **마지막 문장 앞(뒤)** 둘 중 하나다. GPT가 문단을 읽고 `앞`/`뒤`/`없음` 중 하나만 답하고, 어느 쪽으로 나눠도 문맥이 어색하면 `없음`으로 그대로 둔다. 문장 길이는 프롬프트 규칙이라 문장 안은 자르지 않는다(`PARA_REFLOW_RULES`). 그 밖의 답은 잘못된 응답으로 보고 그 문단을 그대로 둔다.
- 잠그는 줄: `#`(제목·소제목·해시태그), 표, 리스트, 인용, 이미지, 코드펜스, 구분선, 굵은 글씨만 있는 줄, `[[`(강조·주의 태그는 프롬프트상 독립 문단).
- 나누지 않는 문단(`para_long_targets`):
  - 여러 줄로 된 문단. 한 줄 바꿈으로 이어진 블록이며, B·Claude 도입부의 시적 줄바꿈 등 줄바꿈 자체가 형식인 경우다.
  - 문단 안에 `[[`가 섞인 문단. 프롬프트 위반이며, 억지로 떼면 문장이 잘린다.
  - 해시태그 바로 앞 문단(면책 문장 "별도 한 줄").
  - 도입부(첫 `##` 소제목 앞 문단).
- 샘플 199개로 잰 결과(위 제외 규칙 넣기 전): 150자 기준이면 175개 글에서 호출(글당 긴 문단 평균 2.9개, 입력 약 1천 자). 200자 기준이면 58개 글에서만 호출한다.
- 비용: 글 1개당 1원 안팎. gpt-4.1-mini 공개 단가(입력 $0.40/백만, 출력 $1.60/백만) 기준이며, 2026-10-05에 OpenAI 가격 페이지는 확인하지 못했다(접속 차단).
- 시험: 사용자 샘플(`eval/samples/2027_9월모평_등급컷.md`, A·Claude)에서 150자 넘는 문단 4개만 문장 사이에서 나뉘었다. 샘플 199개에 가짜 응답을 넣어 글자 대조, 잠금 줄, 기존 문단 유지, 여러 줄 블록 유지를 확인했다(문제 0건). 가상 화면(xvfb)에서는 붙여넣기→확정→정리→저장 흐름을 확인했다. **실제 GPT로는 아직 돌려 보지 않았다.**

## 코드 카드 (선택 기능) — 정책뉴스 Ver10.08 · 복지로 Ver10.07 (2026-10-13)

"그림은 AI, 글자는 코드". 화면은 위에서 아래로 ① 카드용 프롬프트 복사(→ Claude) → ② Claude 답변의 JSON 블럭 붙여넣기 → ③ 퍼플렉시티 그림 선택(옆에 카드 작업폴더 열기) → ④ 카드 만들기 순서다. 카드용 프롬프트(C V19·⑦ V8)는 답변을 **장면 프롬프트 블럭(→ 퍼플렉시티)과 맨 끝 JSON 블럭(→ ②) 두 개만** 내므로 Claude 답변에서 복사는 두 번이다. 기존 인포그래픽 흐름(프롬프트 C·⑦ 복사 → GPT가 그림 전체)은 그대로 두고, 인포그래픽 탭(정책 5탭, 복지로 ⑥탭) 아래 **"🧩 코드 카드 (선택)" 체크를 켤 때만** 보이는 추가 경로다. 두 프로그램에 같은 코드(`card_*`)가 들어 있다.

1. **① 카드용 프롬프트 복사** → Claude에 붙여넣기 — 정책은 `정책뉴스_C_카드설계.md`(C V19), 복지로는 `복지로_7_카드설계.md`(⑦ V8, 파일명은 설정 탭에서 바꿀 수 있다). 입력값에 본문·핵심 키워드·모드(웹)·직전 썸네일 shape(마지막으로 만든 값)를 붙인다. 간소화(같은 대화창) 복사도 있다.
2. **② JSON 블럭 붙여넣기** — Claude 답변 맨 끝 JSON 블럭을 칸에 붙여넣는다(답변 전체를 넣어도 마지막 JSON 블럭을 쓴다). 칸을 비워 두면 카드 작업폴더의 .json/.txt/.md 파일을 읽는다. 설계도의 notes(생략 사유·아이콘 추가 요청)가 있으면 안내 줄에 보여 준다. 답변의 장면 프롬프트 블럭은 Claude 화면에서 바로 퍼플렉시티로 복사한다(프로그램을 거치지 않음).
3. **③ 퍼플렉시티 그림 선택** — 다운로드 폴더에서 열리고, 고른 그림은 카드 작업폴더(글 폴더 안 `_카드작업`)에 바로 복사된다. 바로 옆 "📁 카드 작업폴더 열기"로 그 폴더를 열어 직접 넣어도 된다(이름 무관, png·jpg·webp). ④는 그 폴더의 가장 최근 그림을 쓴다.
4. **④ 카드 만들기 → MD 폴더에 넣기** — `Naver_blog_SVG Card_images/cards/make_cards.py`를 실행(Playwright + 크롬)해 `_카드작업/out`에 PNG를 만들고, 설계도의 `heading`으로 MD 소제목을 찾아 **제목·소제목 이름(분할은 `_1`·`_2`)으로 글 폴더에 복사**한다. 이름 규칙은 기존과 같아(정책: 8)키워드 등록 `_copy_matched_assets`, 복지로: ⑥ [복사] 버튼) 키워드 등록·포스팅 프로그램이 그대로 찾는다. 넣기 전에 목록을 보여 주고 묻는다. 같은 이름의 기존 그림은 `_카드작업/_이전이미지`로 옮긴다. 소제목을 못 찾은 그림은 `out`에만 남기고 알린다. "썸네일만 다시 만들기"도 있다.

## MD 읽는 규칙 (프롬프트 출력 형식과 맞물림)

- 첫 `# ` 줄 = 제목. 소제목은 `## `만 인식한다(인용구·소제목 이미지 대상).
- `###`~`######`는 기호를 떼고 일반 문단으로 입력한다(Ver9.16 전에는 통째로 빠졌다).
- 빈 줄 = 문단 구분(Enter 2회), 줄바꿈만 = Enter 1회. **한 줄에 4문장 이상이면 중간에 빈 줄을 하나 더 넣는다**(`_get_paragraph_breaks`).
- `[[강조:…]]`·`[[주의:…]]` 배경 강조, `**…**` 볼드+색, 리스트 `- `·`• `·`  - `·`1. `, 표 `|`.
- 해시태그: 단어가 전부 `#`인 **마지막 줄**에서 뽑아 순서를 섞고 3~5개만 넣는다(3개 미만이면 전부). 이 태그로 포스팅 이력 엑셀에서 같은 카테고리 글을 찾아 "함께 보면 좋은 글"을 붙인다.
- 끝부분 순서: 내부링크 → 요약 동영상 → 마무리 문구(설정) → 스티커 → 태그.
