# 지식인 관리 프로그램

`kin_manager.py` — 사용자가 쓰는 지식인 관리 프로그램(tkinter, Windows). 지금 버전은 **Ver10.05**(2026-10-05)다. 처음 받은 파일 이름은 `…GUI…2026-09-28…Final_Ver_9.28.py`이고, 저장소에서는 영문 이름으로 둔다. 줄바꿈은 원본 그대로 CRLF로 유지한다.

- 첫 커밋은 받은 원본 그대로, 다음 커밋부터 수정분이다. `git log -p program/kin_manager.py`로 바뀐 내용을 볼 수 있다.
- 변경 이력은 파일 맨 위 docstring(`[변경 이력 요약]`)에 기존 형식대로 적는다.
- 정책뉴스·복지로 프로그램은 다른 대화에서 다룬다. 여기서는 지식인만 다룬다.

## 탭 구성

1)질문수집 · 2)질문적합분석(클로드) · 3)퍼플렉시티 수집 · 4)퍼플렉시티 자료검증(클로드) · 5)API설정 · 6)자동각색(API) · 7)1차 각색 · 8)2차 각색 · 9)썸네일/인포그래픽 · 10)통합 키워드 등록 · 11)주제 키워드 등록 · 12)포스팅 이력관리

- 최종 글 저장은 8)2차 각색의 `save_web_2nd_result` 한 곳뿐이다. 흐름: 붙여넣기 → "✅ 최종 확정"(H1 교체 + GPT 게시판 판정, 백그라운드) → "저장"(`_strip_ai_ui_chrome` → 포스팅DB 중복 차단 → MD 저장 → 포스팅DB·게시판목록.txt 기록).
- API: `Naver_blog_config_지식인.json`의 키로 OpenAI·Gemini·Claude 클라이언트를 만든다. 지금 실제로 쓰는 곳은 주제 분류와 게시판 판정이다(`gpt-4.1-mini-2025-04-14`, temperature 0).
- 포스팅 프로그램은 MD를 그대로 읽고, 빈 줄 하나를 문단 구분으로 쓴다.

## 저장 전 모바일 문단 정리 (Ver10.05)

- 8)탭에 "📱 문단 정리(GPT)" 체크(**기본 꺼짐**)와 기준 글자 수 칸(**기본 150자**, 80~400)이 있다. 두 값 모두 재실행 후에도 유지된다. 켜 두면 "✅ 최종 확정" 때 게시판 판정과 함께 백그라운드로 돈다.
- **기존 문단 구분은 그대로 두고, 기준을 넘는 문단만 나눈다.** 문단을 합치지는 않는다. 각색 결과는 이미 빈 줄로 1~3문장씩 나뉘어 있기 때문이다(샘플 문단 4,000개 기준 중간값 약 100자, 150자 초과 12%).
- 기준을 넘는 문단이 없으면 GPT를 부르지 않는다. 있으면 그 문단들만 묶어 글 1개당 1번 호출한다.
- GPT(`PARA_REFLOW_MODEL`, gpt-4.1-mini)는 나눌 자리(문장 번호 묶음)만 JSON으로 답한다. 코드가 원래 문장을 그대로 이어 붙이며 나눈 자리에만 빈 줄을 넣는다. 공백을 뺀 전후 본문이 다르거나 응답이 잘못되면 원본을 쓴다.
- 잠그는 줄: `#`(제목·소제목·해시태그), 표, 리스트, 인용, 이미지, 코드펜스, 구분선, 굵은 글씨만 있는 줄, `[[`. 문단 중간의 `[[강조]]`는 앞 문장에 붙여 두어 나뉜 뒤 줄 맨 앞으로 오지 않게 한다.
- 나누는 기준은 `PARA_REFLOW_RULES`에 있다: 각 문단이 기준 글자 수 이하, 뜻이 이어지는 문장(조건·예외, 숫자·기준, 원인·결과)은 같은 문단, 한 문장짜리 짧은 조각을 만들지 않음, 나누기 어려우면 나누지 않음.
- 샘플 199개로 잰 결과: 150자 기준이면 175개 글에서 호출(글당 긴 문단 평균 2.9개, 입력 약 1천 자). 200자 기준이면 58개 글에서만 호출한다.
- 비용: 글 1개당 1원 안팎. gpt-4.1-mini 공개 단가(입력 $0.40/백만, 출력 $1.60/백만) 기준이며, 2026-10-05에 OpenAI 가격 페이지는 확인하지 못했다(접속 차단).
- 시험: 샘플 199개에 가짜 응답을 넣어 글자 대조, 잠금 줄, 기존 문단 유지를 확인했다(문제 0건). 가상 화면(xvfb)에서는 붙여넣기→확정→정리→저장 흐름을 확인했다. **실제 GPT로는 아직 돌려 보지 않았다.**

## 바뀐 점 (Ver10.05)

- 포스팅DB 중복비교의 도입부·마무리는 앞 5줄이 아니라 200자로만 자른다(문단을 잘게 나눠도 같은 범위 비교).
- 고친 버그: 2)탭 탭 전환 새로고침, 크롬 열기 실패 팝업 NameError.
- 쓰이지 않던 코드 삭제: 워터마크, 옛 사전필터링, 질문 피커 팝업, `_copy_web2nd_title`, 썸네일 그룹 탐색, `select_classifier_file`.
