# 블로그 이미지 반자동화: 연결 프로그램 수정 가이드

> 이 문서는 **연결 프로그램(Ver10.02 계열)을 수정하는 클로드**에게 그대로 전달하는 작업 지시서입니다.
> 이미지를 그리는 코드(`make_cards.py`)와 프롬프트(정책뉴스 C V18, 복지로 ⑦ V7)는 이미 완성되어 있습니다.
> 연결 프로그램은 **AI 답변을 나누고, 파일을 저장하고, 실행 명령 하나를 부르는 일**만 하면 됩니다.

## 1. 전체 컨셉: "그림은 AI, 글자는 코드"

| 부분 | 담당 | 비고 |

| 썸네일 배경 그림 (글자 없는 장면) | 퍼플렉시티 컴퓨터 모드(이미지 생성) | **글 1개당 1장**. 한도 절약이 목적 |
| 썸네일 제목 2~3줄 + 시리즈 배지 | `make_cards.py` | 배경 그림 위에 코드로 얹음. 한글 깨짐 없음 |

## 2. 글 1개 처리 흐름

```
[1] 완성 본문 MD + 프롬프트(C 또는 ⑦) → AI(글자 답변)
[2] AI 답변에서 두 가지를 꺼냄
      ├─ 썸네일 장면 프롬프트 (코드블럭)  → 파일명 식별자 00_thumbnail_scene
      └─ JSON 설계도 (마지막 ```json 코드블럭)
[3] 장면 프롬프트 → 퍼플렉시티 이미지 생성 → 00_thumbnail_scene.png 로 저장
[4] 작업 폴더에 spec.json + 00_thumbnail_scene.png 를 같이 둠
[5] python make_cards.py 작업폴더/spec.json  → 작업폴더/out/*.png
[6] out/ 의 PNG를 블로그에 올림 (00_thumbnail.png, 01_…png, 02_…png …)
```

연결 프로그램이 새로 해야 할 일은 [2], [4], [5]입니다. [3]은 지금처럼 사람이 하거나, 프로그램이 퍼플렉시티 화면을 조작해도 됩니다.

## 3. 프롬프트 보내는 규칙 (기존 그대로 유지)

프롬프트 파일 맨 위에는 사람용 메모가 있습니다.

- `> **[참고 메모` 로 시작하는 블록은 **보내지 않습니다**.
- 보내는 범위: `# 제목` 줄 + 첫 번째 `---` 줄 **이후의 본문**.
- 메모 표시 `[참고 메모`와 `---` 줄은 프로그램이 찾는 기준이므로 프롬프트 쪽에서도 바꾸지 않습니다.

시리즈에 따라 프롬프트 파일만 바꿔 끼우면 됩니다. (정책뉴스 → C V18, 복지로 → ⑦ V7)

## 4. AI 답변에서 꺼내는 방법

### 4-1. 이미지 생성 프롬프트 (3줄 구조)

AI 답변에는 이미지 프롬프트가 항상 이 구조로 나옵니다.

~~~
썸네일의 이미지 생성 프롬프트입니다. (모드: 웹)      ← 1행: 코드블럭 밖 라벨
```
(영어 장면 프롬프트 문장)                              ← 2행: 코드블럭 안, 문장만
```
파일명 식별자: 00_thumbnail_scene                      ← 3행: 코드블럭 바로 아래
~~~

꺼내는 규칙:
1. `파일명 식별자: 00_thumbnail_scene` 줄을 찾는다.
2. 그 줄 **바로 위의 코드블럭** 안 문장이 썸네일 장면 프롬프트다.
3. `파일명 식별자: slot_01`, `slot_02`가 있으면 이미지 슬롯 프롬프트다 (아래 4-3 참고).

### 4-2. JSON 설계도

- 답변 **맨 마지막 ` ```json ` 코드블럭** 하나가 설계도입니다.
- 그 안의 글자를 그대로 `spec.json`(UTF-8)으로 저장합니다.
- 저장 전에 `json.loads()`로 한 번 검사합니다. 실패하면 4-4 처리.

### 4-3. 이미지 슬롯 (선택)

- 프롬프트는 글당 최대 2개까지 "이미지 슬롯"(인포그래픽 안에 작은 그림)을 쓸 수 있습니다.
- JSON 안에서는 `"image": "slot_01.png"` 로 표시됩니다.
- **슬롯 그림 파일이 없으면 코드가 자동으로 아이콘으로 대신 그립니다.** 오류가 나지 않습니다.
- 한도를 아끼려면 슬롯은 **생성하지 않아도 됩니다** (기본 권장: 썸네일 1장만 생성).
- 생성한다면 파일명은 `slot_01.png`, `slot_02.png` 로 spec.json 옆에 둡니다.

### 4-4. 오류 처리

| 상황 | 처리 |
|---|---|
| JSON 코드블럭이 없음 | "JSON 설계도를 코드블럭 하나로 다시 출력해줘" 재요청 |
| `json.loads()` 실패 | 오류 메시지와 함께 "JSON 문법만 고쳐서 다시 출력해줘" 재요청 (큰따옴표, 마지막 쉼표가 흔한 원인) |
| 배경 그림(`00_thumbnail_scene.png`)이 없음 | 썸네일만 배경 없이 나옴. 사람에게 알리고 그림 저장 후 `00_thumbnail`만 다시 실행 |
| 배경 그림에 글자가 들어가 있음 | 코드 제목과 겹쳐 보임 → 이미지를 다시 생성 (프롬프트에 글자 금지가 들어 있음) |
| 모르는 아이콘 이름 | 코드가 ⓘ(안내) 아이콘으로 대신 그림. 오류 없음. 결과를 보고 필요하면 `icons.py`에 추가 요청 |

## 5. 작업 폴더와 파일 이름

글마다 폴더 하나를 따로 씁니다. (여러 글을 한 폴더에 넣으면 `out/`이 섞입니다.)

```
작업폴더/2026-10-13_생계비계좌/
  ├─ spec.json                  ← AI가 출력한 JSON 설계도
  ├─ 00_thumbnail_scene.png     ← 퍼플렉시티가 그린 배경 (이름 고정)
  ├─ slot_01.png                ← (선택) 이미지 슬롯
  └─ out/                       ← make_cards.py가 만듦
       ├─ 00_thumbnail.png
       ├─ 01_xxx.png
       └─ …
```

- 배경 그림 파일 이름은 JSON의 `"background"` 값과 같아야 합니다. 프롬프트가 `"00_thumbnail_scene.png"`로 고정해서 출력하므로 그 이름으로 저장하면 됩니다.
- 퍼플렉시티가 `.webp`/`.jpg`로 주면 PNG로 바꾸거나, spec.json의 `"background"` 값을 실제 파일 이름으로 바꿔도 됩니다.
- 결과 이미지는 1080×1080 PNG입니다.

## 6. 실행 명령

```
python make_cards.py 작업폴더/spec.json                 ← 전부 그림
python make_cards.py 작업폴더/spec.json 00_thumbnail    ← 썸네일만 다시
python make_cards.py 작업폴더/spec.json 01_xxx 03_yyy   ← 일부만 다시
```

- `make_cards.py`는 `blog-images/cards/` 안에 있고, 같은 폴더의 `icons.py`, 상위의 `blog-images/fonts/`를 씁니다. **이 폴더 구조를 그대로 두고** 경로만 지정해 부르면 됩니다.
- 결과는 항상 `spec.json`과 같은 폴더의 `out/`에 저장됩니다.
- 성공하면 이미지마다 `저장: 00_thumbnail` 같은 줄이 출력됩니다. 종료 코드가 0이 아니면 실패입니다.
- 프로그램에서 부를 때 예 (파이썬):

```python
import subprocess, sys
r = subprocess.run([sys.executable, r"C:\...\blog-images\cards\make_cards.py", str(spec_path)],
                   capture_output=True, text=True, encoding="utf-8")
if r.returncode != 0:
    print(r.stderr)   # 오류 표시
```

```
pip install playwright
python -m playwright install chromium
```

- 글꼴(Noto Sans KR)은 `blog-images/fonts/`에 들어 있어 인터넷 없이도 됩니다.
- 크롬을 직접 지정하고 싶으면 환경변수 `CHROME_PATH`에 크롬 실행 파일 경로를 넣습니다. 비워 두면 Playwright 기본 크롬을 씁니다.
- 파이썬 3.10 이상.

## 8. 연결 프로그램 수정 체크리스트

- [ ] 시리즈 선택(정책뉴스/복지로)에 따라 프롬프트 파일 C V18 / ⑦ V7 선택
- [ ] 프롬프트 전송 시 `[참고 메모` 블록 제외 (기존 규칙 유지)
- [ ] AI 답변에서 `00_thumbnail_scene` 장면 프롬프트 추출 → 화면 표시 또는 퍼플렉시티로 전달
- [ ] AI 답변에서 마지막 ```json 블록 추출 → `json.loads` 검사 → 글별 폴더에 `spec.json` 저장
- [ ] 배경 그림 `00_thumbnail_scene.png`를 같은 폴더에 저장 (사람이 넣거나 자동 다운로드)
- [ ] `make_cards.py` 실행 → `out/` 결과 확인/열기
- [ ] 오류 시 재요청·재실행 (4-4 표)
- [ ] (선택) 슬롯 그림은 생성 생략 가능. 없으면 아이콘으로 자동 대체

- `make_cards.py`, `icons.py`, `fonts/` 내용 (디자인·레이아웃은 이 쪽 저장소에서 따로 관리합니다)
