지식인 프롬프트와 달리 공식 원문이 있으므로, 원문 오류는 지우지 않고 "(원문 표기)"로 표시·보고하는 방식을 유지한다. 변경 근거는 각 파일 맨 위 메모 블록의 최신 변경 요약에 있다.

문단 규칙은 원래대로 두고, 모바일용 문단 나누기는 저장 전에 관리 프로그램이 따로 처리한다(문장 내용은 바꾸지 않고 줄바꿈만 — 프로그램과 함께 설계 예정).
