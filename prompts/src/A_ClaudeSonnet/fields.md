# A·Claude 주제 필드 설명

주제 파일(`topics/{주제}.md`)은 `@@ 필드명` 줄 아래에 값을 적는다. `?`가 붙은 필드는 없어도 된다.
"줄 안" 필드는 한 줄 값, "블록" 필드는 여러 줄 값이다. `_`로 시작하는 필드(예: `_메모`)는 조립에 쓰이지 않는 기록용이다.

| 필드 | 형태 | 내용 |
|---|---|---|
| 역할 | 블록 | [역할]의 화자 설명 문단 2개 (어떤 분야의 무엇을 정리해온 사람인지, 무엇이 아닌지·어떤 자료를 봐 왔는지) |
| ?역할금지 | 블록 | 이 분야에만 있는 금지 불릿 (예: "- 절세를 넘어선 탈세·편법 조장 표현 금지"). 공통 금지(행정 안내문·판결문 말투, 공포·위로, 가짜 수치·사례, 새 기관명·수치 생성)는 넣지 않는다 |
| ?다루는범위 | 블록 | `[다루는 범위 — 반드시 준수]` 머리줄을 포함한 섹션 전체 |
| 정보항목 | 줄 안 | 보존해야 할 정보 종류 (예: 세율·공제액·신고 기한·납부 기한·기관명·홈택스 메뉴명·가산세 조건·신청 경로·예외사항) |
| 분석손해 | 줄 안 | 실제 손해 예 (예: 가산세·환급 누락·신고 오류) |
| 정보갈래예 | 줄 안 | 정보 갈래 예 (예: 세목별 기준, 시기별 절차, 조건별 분기, 예외 상황) |
| 핵심소재예 | 줄 안 | 도입부 첫 문장에 놓을 핵심 소재 예 (예: 특정 공제 항목, 세율, 기한) |
| 현실흐름 | 블록 | 현실형 흐름 불릿 2~3개 (어떤 과정에서 자주 생기는 상황인지 + 분야별 주의) |
| 화자경험예 | 줄 안 | 일반화된 화자 경험 예문 1개 (따옴표 없이) |
| 문서어 | 블록 | 불릿 3개: "- 치환 예시: …", "- …처럼 실제 검색되는 …명과 … 기관명·메뉴명은 원형을 유지한다", "- …(조문 번호 등)는 제목에 쓰지 않고 소제목·본문에서만 쓴다" |
| 제목키워드예 | 줄 안 | 앞부분 키워드 예 4개, " / "로 구분 |
| 제목차별예 | 줄 안 | 차별 요소 예 3개, 쉼표로 구분 |
| 제목명사범위 | 줄 안 | 이 분야의 구체적 명사 범위 (예: 세목명·공제 항목명·세율·기준 금액·신고 기한·법령 조항) |
| 결합금지예 | 줄 안 | "이미 두 조건을 담은 항목" 예시 문장 1개 |
| 비교축예 | 줄 안 | 비교 대조 소재 예 3개 |
| 질문형예 | 줄 안 | 질문형 종결 예 2개 (따옴표 포함) |
| 서술형종결예 | 줄 안 | 서술형 종결 예 2개 (따옴표 포함) |
| ?제목금지추가 | 블록 | 이 분야의 제목 추가 금지 불릿 |
| 제목유형 | 블록 | A~L 12줄. 각 줄 "X. 유형명 — 한 줄 설명. 예: 예시 제목 (약 N자)". 예시는 1개만 |
| 본문구조 | 블록 | ①~⑥ 6줄 |
| 도입부허용 | 줄 안 | 빠른 결론 제시형 허용 예 (따옴표 포함) |
| 도입부금지 | 줄 안 | 조건까지 다 말해 버린 금지 예 (따옴표 포함) |
| ?도입부예외예 | 줄 안 | ② 갈등·오해형을 쓰는 예외 주제 예. 앞에 공백 하나, 괄호로 (예: …) |
| ?도입부금지추가 | 블록 | 이 분야의 도입부·본문 추가 금지 불릿 |
| 태그 | 블록 | `[[강조: …]]`, `[[주의: …]]` 정의 2줄 |
| 태그갈래예 | 줄 안 | 서로 다른 정보 갈래 예 (예: 공제 조건 + 예외 조건, 신고 기준 + 흔한 오해) |
| ?태그추가 | 블록 | 이 분야의 태그 추가 규칙 불릿 |
| 마무리체감 | 줄 안 | 체감·여운형 마무리가 남겨야 할 현실 맥락 1문장 |
| ?마무리금지추가 | 블록 | 이 분야의 마무리 추가 금지 불릿 |
| 화자느낌 | 줄 안 | 문체 괄호 설명 (예: 직접 세금 신고를 해보고 정리한 사람이 옆에서 말해주는 느낌) |
| 안전규칙 | 블록 | `[… 안전 규칙]` 머리줄을 포함한 섹션 전체 |
| ?추가규칙 | 블록 | 이 분야에만 있는 그 밖의 섹션 전체 (머리줄 포함, 섹션 사이 `────────────────────`) |
| 분량항목 | 줄 안 | 분량을 위해 만들면 안 되는 것 (예: 세율·공제액·기관명) |
| 면책법무예 | 줄 안 | 쓰지 않을 법무 문구 예 (따옴표 포함) |
| 면책조건 | 줄 안 | 면책 문장을 언제 넣는지 한 문장 |
| 면책갈래 | 블록 | 예시 갈래 2개 불릿 ("  - 갈래명: \"예문\"") |
| 해시태그구성 | 줄 안 | 해시태그 구성 기준 (예: 핵심 주제어·관련 세법·제도명·독자 행동 키워드) |
| 해시태그예 | 줄 안 | 예: #연말정산 #종합소득세 |
| 점검정보 | 줄 안 | 점검 8번의 보존 정보 목록 |
| 점검안전 | 줄 안 | 점검 9번: 이 분야 안전 확인 한 문장 |
| ?점검추가 | 블록 | 이 분야 추가 점검 항목 ("15. …"부터) |
