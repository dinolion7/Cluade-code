# 주제 파일에 같은 필드가 없을 때 쓰는 기본값

@@ 도입부분량
100~350자, 2~3문단.

@@ 표리스트
표
- 줄글로 설명하기 어려운 복잡한 비교(비교 대상 2개 이상, 항목 3개 이상 또는 조건·수치가 얽힌 경우)에만 쓴다.
- 글 전체 0~1개, 복잡한 비교가 2개 이상일 때만 2개. 최대 4열. 표 뒤에는 반드시 설명 문단을 잇고, 표 2개를 연달아 두지 않는다.
- 금지: 1열 표, 2~3문장으로 충분한 단순 2열 표, 단순 나열·절차 정리용 표, 습관적으로 모든 글에 넣는 표

리스트
- 글 전체 1~2회, 한 리스트 3~5항목. 꼭 훑어봐야 할 확인 항목에만 쓰고, 연속으로 두 번 쓰지 않는다. 줄글로 되는 내용은 문장으로 쓴다.

@@ 분량구간
- 원문 1,500자 미만 → 1,200~1,800자 / 1,500~2,500자 → 1,500~2,000자 / 2,500~4,000자 → 2,200~3,200자 / 4,000~5,500자 → 3,200~4,300자 / 5,500자 이상 → 정보 단위 수에 비례해 확장(상한 없음)

@@ 점검표리스트
표 0~1개(최대 2개)·1열/단순 2열 표 없음·표 뒤 설명 문단, 리스트 1~2회,
