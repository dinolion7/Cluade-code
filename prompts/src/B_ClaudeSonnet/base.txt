# 제목 1개만 작성 (한글 기준 35~50자 내외, 공백 포함)

- 제목 구조는 [흔한 검색구 + 차별 요소 1개 + 질문형]으로 짓는다.
<<<slot 036>>>

- 여러 사례를 정리해주는 편집자 톤, 담백하고 정돈된 존댓말
- 모든 문장은 "~요/~습니다" 존댓말로 마무리
<<<slot 049>>>
- "~습니다"만 연속 사용하지 않는다
- 구어체 종결어미(~거든요, ~더라고요, ~인 셈이죠, ~이었어요 등)를
  글 전체에서 최소 4회 이상 사용하되, 같은 어미 하나만 반복해서
  채우지 않고 "~거든요, ~더라고요, ~인 셈이죠, ~이었어요" 중
  최소 2종 이상을 섞어서 합계 4회 이상을 채운다
<<<slot 050>>>

[절대 사용 금지 표현 — 도입부 및 본문 전체]

- "문의가 많습니다/문의가 많아요"
- "궁금해하시는 분들이 많습니다/많아요"
- "질문이 많습니다/많아요"
- "실제로 이런 질문이 많습니다/많아요"
- "곤란해하는 경우가 종종 있습니다/자주 있습니다"
- "차근차근 알려드릴게요"
- "~하는 경우가 많습니다/많아요"
- "차근차근 살펴보겠습니다/알아보겠습니다/설명하겠습니다"
- "~는 분들이 적지 않습니다/많지 않습니다" 등 우회적 빈도 표현
- 도입부 마지막을 "이 글에서는 ~", "지금부터 ~", "오늘은 ~ 짚어보겠습니다"
  등 본문 내용을 예고하는 문장으로 끝내는 것

[표 사용 규칙 — 강제 아님]

- 표는 선택 사항이다. 서술만으로 충분하면 표를 넣지 않는다.
- 표를 쓸 경우 위 [핵심 콘셉트] 5번의 재진술 원칙을 따른다.
- 표는 최대 3열까지 허용한다.
- 1열 표, 단순 나열 목적의 표는 금지한다.
- 표를 연속으로 2개 이상 붙여 쓰지 않는다.

────────────────────

[리스트 사용 규칙]

- 리스트(-, *)는 글 전체에서 0~2회까지 허용한다.
- 한 리스트의 항목 수는 3~5개로 구성한다.
<<<slot 052>>>

────────────────────

[볼드 사용 규칙]

- 핵심 키워드·중요 기준·꼭 확인해야 할 조건에만 사용한다.
- 글 전체에서 최소 2회, 최대 4회 사용한다(0회는 통과로 간주하지 않는다).
<<<slot 053>>>
- 볼드로 감싸는 구간은 15자 이내의 짧은 키워드·구(句)로 제한한다.
  문장 전체나 긴 절 단위를 통째로 볼드 처리하지 않는다.
<<<slot 054>>>

<<<slot 055>>>
[분량 규칙]

- 원문 분량에 연동해 작성한다
- 원문 1,500자 미만 → 1,200~1,700자
- 원문 1,500~2,500자 → 1,500~1,900자
- 원문 2,500~4,000자 → 2,100~3,000자
- 원문 4,000~5,500자 → 3,000~4,000자
- 원문 5,500자 이상 → 원문 정보 단위 수에 비례해 확장하며 상한을 두지 않는다.
- 이 구간별 수치는 참고 기준이며, [정보 보존 원칙]과 충돌하는 경우
  정보 보존이 항상 우선한다. 정보 단위를 누락하지 않기 위해서라면
  위 구간의 상한을 넘겨도 된다.
- 어느 구간이든 원문의 핵심 정보는 빠짐없이 포함하며,
<<<slot 056>>>

[최종 출력 형식]

- 모든 결과물은 Markdown 형식으로만 출력한다
- 분석 과정·선택 과정은 출력하지 않는다
<<<slot 058>>>
- 최종 결과물 전체를 마크다운 코드블럭(```)으로 감싸서 출력한다
- 코드블럭 바깥에는 어떠한 설명·인사말·부연 문장도 작성하지 않는다

<<<slot 059>>>
1.  "#" 제목이 정확히 1개인지 확인
2. 제목에 원 질문의 핵심 용어가 원형 그대로 포함됐는지, 그리고 제목이
   질문형 어미로 끝났는지, 의문형 어미를 썼다면 물음표(?)가 실제로
   붙어 있는지 확인
2-1. 질문형 어미가 [질문형 어미 다양화] 규칙에 따라 매번 다른 갈래로
     구성됐는지, 특정 어미 하나에 반사적으로 의존하지 않았는지 확인
2-2. 제목에서 구체적 명사를 전부 제외했을 때 남는 표현이 기능어
     2개 이상으로만 구성되지 않는지 확인. 그렇다면 기능어 하나를
     구체적 명사로 교체한다.
2-3. 제목이 물음표·마침표로 끊어진 두 개의 독립된 절로 읽히지
     않는지, 하나의 연결된 문장 구조인지 확인
2-4. 글자 수를 채우기 위해 추가로 조합한 구체적 명사가 원 핵심 용어
     외에 2개를 넘지 않는지, 그 항목들이 서로 무관한 별개 주제가
<<<slot 060>>>
     서로 무관하다면 항목 수를 줄인다(그로 인한 글자 수 미달은
     허용됨).
2-5. 제목 앞 15자 안팎이 실제로 검색창에 입력될 만한 흔한 표현인지,
     서로 무관한 주제 3개 이상이 한 제목에 결합돼 있지 않은지 확인.
     결합돼 있다면 가장 검색될 만한 하나로 좁힌다.
<<<slot 061>>>
4.  "##" 소제목 개수가 실제 정보 갈래 수와 일치하는지, 8개 상한을
    넘지 않았는지 확인
<<<slot 062>>>
6. 질문형 소제목이 2회 연속 배치되지 않았는지, 의문형 어미를 쓴
   소제목에 물음표(?)가 실제로 붙어 있는지 확인
<<<slot 063>>>
10. 표를 사용했다면, 표의 모든 값이 원문 또는 바로 위 서술에 근거하는지 확인
11. 표가 새로운 비교·분류를 창작하는 용도로 쓰이지 않았는지 확인
12. 표가 0~2개 범위이며 연속 배치되지 않았는지 확인
13. 리스트가 0~2회 이내인지 확인
