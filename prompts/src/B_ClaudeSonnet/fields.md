# B·Claude 주제 필드 설명

주제 파일(`topics/{주제}.md`)은 `@@ 필드명` 줄 아래에 값을 적는다. `?`가 붙은 필드는 없어도 된다.
"줄 안" 필드는 한 줄 값, "블록" 필드는 여러 줄 값이다. `_`로 시작하는 필드(예: `_메모`)는 기록용이다.

| 필드 | 형태 | 내용 |
|---|---|---|
| 역할 | 블록 | [역할]의 화자 설명 문단 2개 (화자 이름과 다루는 분야 / 무엇이 아니고 어떻게 정리하는 사람인지) |
| 화자명 | 줄 안 | 화자 이름 (예: 머니노트, 차박사) |
| ?역할금지 | 블록 | 이 분야에만 있는 금지 불릿. 공통 금지(행정 안내문·판결문 말투, 공포·위로, 가짜 수치·사례, 새 기관명·수치 생성)는 넣지 않는다 |
| ?다루는범위 | 블록 | `[다루는 범위 — 반드시 준수]` 머리줄을 포함한 섹션 전체 |
| 고유명사 | 줄 안 | 원형을 살릴 고유명사 종류 (예: 세목명·공제명·기관명) |
| 문서어 | 블록 | 불릿 2~3개: "- 치환 예시: …", "- …처럼 실제로 검색되는 … 용어는 원형을 유지한다", "- …(판결·법리 용어 등)는 제목에 쓰지 않고 소제목·본문에서만 쓴다" |
| 정보항목 | 줄 안 | 보존해야 할 정보 종류 |
| 고유명사대조 | 줄 안 | 대조 목록에 넣을 이 분야 이름 종류와 예 (예: 공제명(예: 국세청, 홈택스, 근로장려금, 연말정산 간소화서비스, 세무서 등)) |
| 분석손해 | 줄 안 | 실제 손해 예 (예: 가산세·환급 누락) |
| ?도입부방향예외 | 줄 안 | 결론 방향을 단정하지 않을 주제 설명. 앞에 공백 하나 (예: " 단, 부당해고 인정 여부처럼 …은 방향을 단정하지 않고 암시만 남긴다.") |
| 도입예시제목 | 줄 안 | 도입부 예시의 가정 제목 |
| 도입예시키워드 | 줄 안 | 그 제목의 앞부분 키워드 |
| 도입예시 | 블록 | 시적 줄바꿈 도입부 예시 (각 행 앞 3칸 들여쓰기) |
| 제목차별예 | 줄 안 | 차별 요소 예 3개, 쉼표 구분 |
| 제목명사범위 | 줄 안 | 이 분야의 구체적 명사 범위 |
| 결합금지예 | 줄 안 | "이미 두 조건을 담은 항목" 예시 문장 1개 |
| ?제목금지추가 | 블록 | 이 분야의 제목 추가 금지 불릿 |
| 제목예시 | 블록 | 좋은 예 2개, 나쁜 예 2~3개 (원본 형식 그대로) |
| 맺음말예 | 줄 안 | 가벼운 맺음말 예문 1개 (따옴표 없이) |
| ?마무리금지추가 | 블록 | 이 분야의 마무리 추가 금지 불릿 |
| 안전규칙 | 블록 | `[… 안전 규칙]` 머리줄을 포함한 섹션 전체 (불확정성 문구 재구성 원칙 포함) |
| ?추가규칙 | 블록 | 이 분야에만 있는 그 밖의 섹션 전체 (머리줄 포함) |
| 분량항목 | 줄 안 | 분량을 위해 만들면 안 되는 것 |
| 해시태그예 | 줄 안 | 예: #연말정산 #종합소득세 |
| 점검정보 | 줄 안 | 점검 5번의 보존 정보 목록 |
| 점검안전 | 줄 안 | 점검 9번: 이 분야 안전 확인 (단정 표현·조장 표현·불확정성 문구 배치 등) |
| ?점검추가 | 블록 | 이 분야 추가 점검 항목 ("12. …"부터) |
