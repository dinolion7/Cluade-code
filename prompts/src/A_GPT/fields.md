# A·GPT 주제 필드 설명

주제 파일(`topics/{주제}.md`)은 `@@ 필드명` 줄 아래에 값을 적는다. `?`가 붙은 필드는 없어도 된다.
"줄 안" 필드는 한 줄 값, "블록" 필드는 여러 줄 값이다. `_`로 시작하는 필드(예: `_메모`)는 기록용이다.

| 필드 | 형태 | 내용 |
|---|---|---|
| 역할 | 블록 | [역할]의 화자 설명 문단 2개 (몇 년 상담한 어떤 분야 실무 전문가인지·무엇을 줄여 주는지 / 어떤 기관 창구 직원처럼 어떻게 전달하는지) |
| 역할규칙 | 블록 | [역할] 아래 "- …합니다." 불릿 중 이 분야 것 (글의 범위, 확장 금지 분야, 임의 생성 금지 항목, 이 분야 조장 금지, "○○ 안내문을 그대로 옮긴 듯한 말투는 피합니다" 등). 공통인 "판결문·행정문 스타일·공포 조장", "가짜 사례·수치"는 넣지 않는다 |
| ?다루는범위 | 블록 | `[다루는 범위 — 반드시 준수]` 머리줄을 포함한 섹션 전체 |
| 고유명사 | 줄 안 | 원형을 살릴 고유명사 종류 (예: 제도명·기관명·계약 유형·특약 명칭) |
| 초안문서어 | 줄 안 | 초안에 흔한 문서어 예 3~4개 (예: 소득금액·과세표준·기납부세액·환급액) |
| 문서어 | 블록 | 불릿 3개: "- A→B, C→D 처럼 바꾼다", "- 실제로 검색되는 제도명·기관명(…)은 원형 그대로 둔다", "- …와 사건번호·조항 번호는 제목에 넣지 않는다" |
| 정보항목 | 줄 안 | 보존할 정보 종류 |
| 전개흐름 | 줄 안 | 직선 전개 순서 (예: 핵심 쟁점 → 신고 기준 → 계산 흐름 → 실제 결과) |
| 제목키워드 | 줄 안 | 앞 15자에 둘 핵심 키워드 목록 (·로 구분) |
| 제목명사범위 | 줄 안 | 이 분야의 구체적 명사 범위 |
| 결합금지예 | 줄 안 | "이미 두 조건을 담은 항목" 예시 문장 1개 |
| 제목유형분산 | 줄 안 | 섞어 쓸 제목 유형 (예: 환급확인형·신고판단형·공제검토형·세액해석형·가산세주의형) |
| ?제목금지추가 | 블록 | 이 분야의 제목 추가 금지 불릿 |
| 제목좋은예 | 블록 | "- 예시 (약 N자)" 2~3줄 |
| 제목나쁜예 | 블록 | "- 예시 (이유)" 3~4줄. 원본에 이유가 없으면 짧게 붙인다 |
| 도입상황 | 줄 안 | 도입부가 시작할 실제 과정 (예: 실제 홈택스·연말정산·종합소득세 신고 과정) |
| ?도입부방향예외 | 줄 안 | 방향을 단정하지 않을 주제. 앞에 공백 하나 (예: " 단, …은 방향을 단정하지 않는다.") |
| 도입출발예 | 블록 | 출발점 예시 2~3개 ("- …") |
| 소제목우선 | 줄 안 | 우선할 소제목 소재 (예: 실제 신고 흐름·오해 지점·자동 반영과 직접 입력 구분·환급·추가 납부 기준) |
| 소제목예 | 줄 안 | 좋은 소제목 예 3개, " / "로 구분 |
| 마무리맥락 | 줄 안 | 마무리가 남길 현실 맥락 한 구절 |
| 마무리요소 | 줄 안 | 마무리 요소 목록, " · "로 구분 |
| ?마무리금지추가 | 블록 | 이 분야의 마무리 추가 금지 불릿 |
| 말투 | 줄 안 | 예: 국세청 안내문처럼 딱딱하지 않게, 실제 세무서 민원실에서 차분히 설명하는 말투를 유지한다 |
| 용어설명 | 줄 안 | 예: 연말정산·결정세액·원천징수·종합소득세 등 세무 용어는 그대로 쓰되, 필요하면 쉬운 표현으로 한 번 더 풀어 준다. |
| 과설명예 | 줄 안 | 이미 알 만한 표현 예 (예: 홈택스·연말정산·원천징수·공제 등) |
| 실제흐름 | 블록 | 실제 흐름 불릿 4~5개 |
| 안전규칙 | 블록 | `[… 안전 규칙]` 머리줄을 포함한 섹션 전체 |
| ?추가규칙 | 블록 | 이 분야에만 있는 그 밖의 섹션 전체 (머리줄 포함) |
| 표예시 | 블록 | "예시" 줄 + 마크다운 표 |
| 볼드예시 | 블록 | "좋은 예" 줄 + 예문 1~2개 ("- …") |
| ?패턴추가 | 줄 안 | 이 분야 패턴 방지 추가 문장. 앞에 공백 하나 |
| 전개구조 | 블록 | ①~⑥ 전개 구조 6줄 |
| ?설명축 | 블록 | `[… 카테고리별 설명 축]` 머리줄을 포함한 섹션 전체 |
| 분량항목 | 줄 안 | 분량을 위해 만들면 안 되는 것 |
| 면책법무예 | 줄 안 | 쓰지 않을 법무 문구 예 (따옴표 포함) |
| 면책조건 | 줄 안 | 면책 문장을 언제 반드시 넣는지 한 문장 |
| 면책갈래 | 블록 | 예시 갈래 2개 ("  - 갈래명: \"예문\"") |
| 해시태그예 | 줄 안 | 예: #연말정산 #종합소득세 |
| 점검정보 | 줄 안 | 점검 5번의 보존 정보 목록 |
| 점검안전 | 줄 안 | 점검 6번: 이 분야 안전 확인 한 문장 |
| ?점검추가 | 블록 | 이 분야 추가 점검 항목 ("12. …"부터) |
