# 각색 프롬프트 모듈 관리

## 폴더
- `original/` — 받은 원본 그대로 (수정 금지, 회귀 비교 기준). 목록은 `INDEX.md`
- `src/` — 편집하는 곳
  - `src/{페르소나}_{모델}/base.md` — 그 스타일의 공통 본문(압축본). `{{필드}}` 자리에 주제별 내용이 들어감 (`{{?필드}}`는 없어도 됨)
  - `src/{페르소나}_{모델}/topics/{주제}.md` — 주제별 필드 값 (`@@ 필드명` 아래 값). `_메모`는 정리 기록
  - `src/{페르소나}_{모델}/fields.md` — 필드 설명서, `defaults.md` — 주제가 덮어쓸 수 있는 기본값(건강 형식 등)
  - `src/health/1검수.md` — 건강 ②검수(모든 스타일 공통), `src/health/2편집.md` + 스타일별 `health.md` — 건강 ③편집
- `dist/` — 조립 결과 (자동 생성, 직접 수정하지 않음). 실제 사용은 이 파일

## 명령
```
python3 tools/build.py    # src → dist 조립
```
- 공통 규칙을 고칠 때는 해당 스타일의 `base.md`만, 주제만의 내용은 `topics/{주제}.md`만 고친 뒤 build 한다.
- `tools/verify.py`, `tools/split.py`는 1단계(원문 그대로 분리) 검증용으로 남겨 둔 것이다. 2단계부터는 dist가 original과 의도적으로 다르다.

## 진행 단계
1. 원문 그대로 분리 + 원본 재현 검증 (완료, 42개 전부 일치)
2. 중복·누락·불일치 정리, B의 "스타일 A와 다르게" 문구를 자기완결형으로 전환 (완료)
3. 축약 (완료, 약 40~48% 감소)
4. 원본 vs 수정본 실제 출력 비교 테스트
5. 누락 조합(B·건강 Claude/GPT) 생성
