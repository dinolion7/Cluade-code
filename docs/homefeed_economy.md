# 경제 홈판 설계 — 결정 기록

하나씩 정하고, 정해진 것만 "확정"으로 옮긴다. 근거 자료는 `eval/samples/homefeed/`.

## 확정 (사용자 결정)
1. 홈판 주제별로 간다. **경제부터**(사용자가 경제를 가장 많이 해 봄). 엔터·뷰티·스포츠는 나중에.
2. 홈판은 추천 알고리즘 노출 — 제목은 피드에서 멈추게 하는 후킹 위주, 먼저 추천 AI에 선택받기, 가능하면 검색도 잡기.
3. 홈판 C(인포그래픽) 프롬프트는 쓰지 않는다. 기존 키워드용 인포그래픽을 참조하되 **썸네일은 실사 스타일**로 새로 만든다. 실사 프롬프트는 사용자가 찾아서 준다.
4. 설정은 사용자가 로컬에서 바꾼다. 시험은 개발이 끝난 뒤 한 번에 한다.

## 결정할 것 (순서대로 하나씩)
| # | 항목 | 내 제안 | 상태 |
|---|---|---|---|
| 1 | 올릴 블로그 — 기존 정책·복지로 블로그와 섞기 / 분리 | 섞되 블로그 전체를 "생활 돈" 한 주제로 좁힘(정책·복지로는 돈 관련만 남김). 홈판 = 피드용, 정책·복지로 = 검색용, 같은 주제 다른 틀 | **논의 중** |
| 1-1 | 정책뉴스 범위 좁히기 | 받는 돈·내는 돈·빌리는 돈·모으는 돈 4갈래만. 독자는 40~60대로 고정. 키워드 = 세대 + 제도 + 금액 | **논의 중** |
| 1-2 | 소스처 | 근거는 공식 자료(정책브리핑 + 국가데이터처·국민연금·건보공단·국세청·금융위 보도자료), 주제 고르기는 홈판·데이터랩에서 뜨는 것. 뉴스 기사는 주제 찾기에만 | **논의 중** |
| 2 | 글 유형 | 통계형(자유남편) + 생활 계산형(스크랩유미). 주식 시황·종목형 제외 | 대기 |
