# 경제 홈판 설계 — 결정 기록

하나씩 정하고, 정해진 것만 "확정"으로 옮긴다. 근거 자료는 `eval/samples/homefeed/`.

## 확정 (사용자 결정)
1. 홈판 주제별로 간다. **경제부터**(사용자가 경제를 가장 많이 해 봄). 엔터·뷰티·스포츠는 나중에.
2. 홈판은 추천 알고리즘 노출 — 제목은 피드에서 멈추게 하는 후킹 위주, 먼저 추천 AI에 선택받기, 가능하면 검색도 잡기.
3. 홈판 C(인포그래픽) 프롬프트는 쓰지 않는다. 기존 키워드용 인포그래픽을 참조하되 **썸네일은 실사 스타일**로 새로 만든다. 실사 프롬프트는 사용자가 찾아서 준다.
4. 설정은 사용자가 로컬에서 바꾼다. 시험은 개발이 끝난 뒤 한 번에 한다.
5. **기본 방향: 기존 키워드(검색용) 프롬프트에 홈판 스타일을 얹어 업그레이드한다.** 정책뉴스·복지로 각각 1세트, 하나의 스타일로 피드와 검색을 같이 잡는다. 블로그는 하나(nnuiz).
6. 블로그 하나에만 올린다. C는 블로그 B용(V13) 하나만 쓰고, 이미지(썸네일·인포그래픽)는 전부 새로 만든다.
7. 이미지는 **GPT만** 쓴다. 프롬프트D(재미나이용)는 없앤다. 썸네일은 실사로 바꾸면서 **색상도 바꾼다**.

## 기존 블로그 현황 (blog.naver.com/nnuiz, 2026-10-05 사용자 제공)
- 글 226개, 이웃 35명. 카테고리 8개: 생활·교통·혜택 / 육아·교육 / 건강·의료 / 금융·세금 / 일자리·노동 / 주거·부동산 / 노인·장애·돌봄 / 기타
- 최근 30개 조회수 2~48(대부분 10 이하). 높은 글: 토픽 시험 일정 48, 레테브모 급여 27, 루게릭 요양병원 18 — 특정 대상 검색
- 최근 30개 주제 분류(내 판단): 돈이 중심 약 15(아동수당·자립펀드·축하지원금·온누리 환급·개인투자용 국채·2주택 비과세·모두의카드·청약통장·장학금·공익신고 보상금 등), 돈이 일부 약 6(통행료·본인부담금·요금 할인 등), 돈과 무관 약 9(독감 접종·인삼 요리·백신 이물·토픽·일학습병행·연기감지기 등)
- 제목이 전부 같은 틀("정책명 + 내용, ~일까?" 긴 질문형). 대상이 좁은 주제(건설근로자·면세유 농가·공익신고자) 많음
- 판단: 쌓인 힘이 크지 않아 전환 손실이 작고, 글 절반이 이미 돈 주제라 경제 블로그로 바꿀 바탕은 있음

## 정책뉴스 수정 계획 (2026-10-05 사용자 "진행해")
진행: 0 V2 완료 · A V20 완료 · B V21 완료(홈판 A·B 파일은 합치고 삭제) · C V14 완료(에디토리얼 일러스트 + 문구, 실사는 거부감으로 제외 — 사용자) · 프로그램 Ver10.06 완료(가짜 GPT 응답으로만 시험)

순서: 0 → A → B → C(실사 프롬프트 받은 뒤) → 프로그램(Ver10.05 바탕)

- **0 후보 1차 선별:** 돈 4갈래에 들어가는지로 거름(건강·교육은 지원금·의료비 각도일 때만). 노후·소득·자산·부채·연금 통계 발표는 제외 대신 통과. 우선순위 상 = 40~60대가 넓게 겪는 주제 + 금액이 구체적. 출력 열(링크/제목/우선순위/한줄사유)은 프로그램이 읽으므로 그대로 두고, 갈래는 한줄사유 앞에 [받는 돈] 식으로 적음
- **A 전략:** 0단계 판정에 같은 기준. 제목 구조 = [메인(+서브) + '속마음 후킹' 8~12자], 쉼표 1개, [롱테일 + 세부사항]. 속마음 후킹이 기존 "변화" 자리를 대신하고 앞 25자 안에 메인 + 후킹이 다 들어감. 길이 40~55자(60자 상한 유지), 쉼표 1개·앞부분 30자 이내 유지. 홈판 A의 후킹 패턴 이식, 홈판 A의 20~40자 규칙은 버림
- **B 작성:** 도입부 첫 화면이 제목의 속마음을 받아 줌(독자 상황 한 줄 → 메인 키워드). 글쓴이 실제 경험(입력 있을 때만 1인칭) 가져옴. [계산 예시]를 "내 돈 얼마" 표 1개로 적극 사용. 말투·마무리 틀은 그대로
- **C 이미지:** 썸네일 문구(2~3줄, 숫자 1 + 감정어 1)와 실사 장면을 C가 B 완성본을 읽고 만듦(B의 MD 코드블럭에 섞지 않음). 실사 프롬프트·색상 변경 반영해 새로 씀
- **프로그램:** 세트 선택(검색/홈판) 없앰, 제목 점검을 새 규칙에 맞춤(앞 핵심구 검색 때 따옴표 부분 처리 포함), 경험 입력을 항상 붙임, D 탭 정리, 저장 전 문단 정리 이식
