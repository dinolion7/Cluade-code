# 복지로 프로그램 개선 목록 (Ver10.07 기준)

정책뉴스 때와 같은 방식: 사용자와 대화하며 모으고, 사용자가 요청하면 한 번에 코드에 반영한다. 반영 전까지 코드는 건드리지 않는다.

현재 탭: ① 중앙부처복지서비스 · ② 지자체복지서비스 · ③ 리스트업 · ④ 포스팅 관리 · ⑤ 블로그 스크랩 · ⑥ 인포그래픽 작업 · ⑦ 키워드 등록 · ⑧ 포스팅 이력관리 · ⑨ 설정

## 1. 정책뉴스(Ver10.09~10.10)에서 고친 것 중 같은 컨셉 적용 (2026-10-14 요청)

정책뉴스 수정 항목을 복지로 코드와 하나씩 대조했다.

**적용할 것**
- **"🔍 통합"(네이버 통합검색) → "📋 제목 복사"** (④ 포스팅 관리 탭)
  - 제목 후보 4줄 각각의 "🔍 통합" → "📋 제목 복사"(그 후보 제목 복사)
  - 직접 입력 줄의 "🔍 통합" → "📋 제목 복사"(입력칸 제목 복사)
  - 아래 버튼 줄 "🔍 제목 통합검색" → "📋 제목 복사"(선택 항목의 최종각색 제목 복사)
  - 통합검색을 여는 코드 분기는 지운다. 🔍 블로그·앞구·뒷구·🔍 제목 블로그검색은 그대로. 버튼 폭은 정책뉴스처럼 줄 폭이 넓어지지 않게 맞추고 가상 화면에서 전후 폭을 잰다.
- **탭 이름 "⑥ 인포그래픽 작업" → "⑥ 인포그래픽 작성"** — 정책뉴스 "4)인포그래픽 작성"과 같은 이름. 코드 안 안내 문구·주석의 "인포그래픽 작업"(약 10곳)도 같이 바꾼다(변경 이력은 그대로).
- **코드 카드 "③ 퍼플렉시티 그림 선택…" → "③ 퍼플렉시티/GPT 그림 선택…"** (아래 대기 항목을 여기로 옮김)

**해당 없음(복지로에 같은 기능이 없거나 이미 그렇게 되어 있음)**
- 다중뉴스 사전검토 탭·프롬프트0 — 복지로에 없음(Gemini 사전스크리닝은 Ver10.06에서 이미 삭제)
- 워터마크처리 탭·Pillow — 복지로에 없음
- 탭 이동을 번호 대신 탭 화면으로 — 복지로는 이미 탭 화면으로 이동한다(`notebook.select(self.settings_tab)`)
- 탭 번호 통일 — 복지로 탭은 ①~⑨로 이미 순서대로다
- 키워드 등록 "중복의심 글 포스팅 허용"(정책 Ver10.07) — 복지로 ⑦ 키워드 등록에는 중복의심 격리 기능 자체가 없다

- **"🌐 검색 키워드로 네이버 열기" 버튼 삭제** (④ 포스팅 관리 탭 키워드 리서치 줄, `_open_naver_with_research_keyword`) — 사용자 답(2026-10-14): 삭제해도 됨. 이 버튼만 쓰는 코드도 같이 지운다(다른 곳이 쓰는 `open_naver_search_in_chrome`은 확인 후 판단).


## 2. [에러] 사전스크리닝이 없어졌는데 프롬프트 복사 때 하라고 나옴 (2026-10-14 요청, ④ 포스팅 관리 탭)

사용자: 사전스크리닝 기능이 따로 있다가 없어졌는데(Ver10.06에서 Gemini ⓪ 삭제), 남은 코드가 살아 있어서 사용자는 그 작업을 안 하는데 프롬프트를 복사하면 하라고 나온다.

코드에서 찾은 후보(어느 문구인지 사용자 확인 필요):
- (가) "⓪+① 사전스크리닝+가치판단 프롬프트+자료 복사" 후 뜨는 첨부 안내 팝업: "경쟁 블로그 샘플 MD(2~5개, '블로그 스크랩' 탭으로 저장)도 함께 첨부하면 [사전 스캔 절차] B까지 한 번에 처리합니다"
- (나) 같은 복사본 안의 문장: "(참고) 공식 첨부자료 PDF와 함께 … 경쟁 블로그 샘플 MD … 첨부하면 [사전 스캔 절차] B까지 함께 수행합니다"
- (다) 통합 프롬프트 파일(① 통합 V10) 자체: [사전 스캔 절차](공식 PDF·경쟁 블로그 직접 분석), 맨 끝 "공식 첨부자료 PDF와 경쟁 블로그 샘플 MD를 이 대화에 실제로 첨부합니다 — … [사전 스캔 절차]부터 수행하는 것을 전제로 합니다"
- (라) 버튼 이름 "⓪+① 사전스크리닝+가치판단…", 상태 값 "🔦 사전스크리닝중", 버튼과 연결되지 않은 옛 함수(`_copy_value_judgment_prompt` — 복사본에 "이전 단계 결과(사전스크리닝)… 저장한 뒤 다시 복사하라" 섹션을 넣음), 옛 Gemini 프롬프트 함수·설정 키
