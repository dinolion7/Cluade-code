## 6. 가치판단을 두 단계로 — 빠른 판정 → (진행일 때만) 자료를 붙여 본 분석 (2026-10-14 요청, 설계안)

**문제:** 지금 ⓪+① 통합 프롬프트(V10, 약 1,260줄·9.7만 자)는 첫 메시지부터 긴 프롬프트 + 공식 PDF + 경쟁 블로그 + 리서치를 한꺼번에 보내고, 포스팅할지 말지(0단계)는 그다음에 정한다. 결국 보류될 서비스에도 사용량을 다 쓴다.

**바꿀 흐름(④ 포스팅 관리 탭, 3번 재배치에 합침)**
- **STEP 1 — 빠른 판정(Claude, 짧은 새 프롬프트):** 복사 = 짧은 판정 프롬프트(약 60~80줄) + 서비스 원문 텍스트 + 첨부파일 이름 목록만(PDF·리서치·블로그 없음).
  출력(코드블럭 하나): 판정(진행/보류) · 돈 갈래 · 이유 한 줄 · **필요 자료**(첨부 서식자료 필요 여부와 이유, 경쟁 블로그 필요 여부) · **리서치 키워드 1~3개**.
  판정 기준 = V10 [0단계] 중 자료 없이 판단 가능한 것(대상이 극소수, 원문이 비었고 첨부도 없음, 종료됐거나 곧 종료, 돈 4갈래에 안 닿음). 애매하면 진행.
  [판정 결과 저장]: 보류면 확인 후 상태를 "⏸ 보류"로. 진행이면 리서치 키워드를 STEP 2 칸에 자동으로 채우고, 필요 자료를 화면에 안내.
- **STEP 2 — 자료 준비:** 키워드 리서치(자동 채워진 키워드로 실행), 경쟁 블로그 입력칸(4번), 첨부 PDF 확인 — 판정이 "필요"라고 한 것만.
- **STEP 3 — 가치판단·전략(본 분석):** 복사 = 통합 프롬프트(V11) + 원문 + 리서치 + 첨부 안내 + 경쟁 블로그 + 빠른 판정 결과. 빠른 판정을 한 **같은 대화창에 이어 붙이는 복사(원문 생략)**가 기본, 새 대화창용 전체 복사도 둔다. 결과 저장은 지금처럼.
- 이후 제목 후보 확정 → 초안 → 최종각색 → 완료 처리(3번 배치 그대로).

**프롬프트**
- 새 파일 `복지로_00_빠른판정.md`(V1) — 위 출력 형식, 짧게.
- `복지로_01_…통합.md` V11 — 입력에 빠른 판정 결과와 리서치 데이터가 이미 있으면 [0단계 이전](리서치 요청)을 건너뛰고, [0단계]는 자료가 있어야 하는 기준(죽은 키워드·레드오션 → 0-1단계 니치 재검토)만 다시 본다. 나머지([사전 스캔 절차]·1~3단계)는 그대로.
- 설정 탭에 "빠른 판정 프롬프트 파일명" 칸 추가.

**정한 것(사용자: 추천안대로, 2026-10-14)**
- 본 분석은 빠른 판정과 **같은 대화창에서 이어서**(원문 생략 복사가 기본, 새 대화창용 전체 복사도 둠).
- 빠른 판정 "보류"는 **확인창 후 "⏸ 보류"로 변경**.

## 7. AI가 키워드 조사를 요청할 때 — 검토 흐름과 버튼 (2026-10-14 요청, 정책뉴스 STEP 1.5 방식)

AI가 키워드 실측을 요청하는 때: 빠른 판정의 "리서치 키워드"(처음), 본 분석 중 "## 키워드 리서치 요청" 블록(V11에서 리서치가 없거나 부족할 때), "재조사 요청 키워드:" 줄(조합형 등).
지금 문제: 요청 키워드 채우기가 **저장된 가치판단 결과의 "재조사 요청 키워드:" 줄만** 읽는다 → "## 키워드 리서치 요청" 코드블럭은 못 읽고, 저장 전에는 못 쓴다. 검토 버튼(검색량·자동완성)은 화면 밖으로 잘려 있다.

**STEP 2 키워드 리서치 칸 — 정책뉴스 STEP 1.5와 같은 모양·같은 버튼 이름 (사용자: 정책뉴스와 달라서 헷갈림, 2026-10-14)**

정책뉴스 줄을 그대로 따른다(한 줄, 같은 순서·같은 이름, "A" → "AI"만 다름):

`검색 키워드: [입력칸] [✖ 입력 지우기] [🔍 키워드 리서치 실행] [🔍 검색량·자동완성 조회] [📋 AI에게 결과 전달]`

- 그 아래 상태 줄 1개(정책뉴스 `tab2_research_status_var`와 같음), 그 아래 정책뉴스식 ①②③ 안내:
  - ① STEP 1 빠른 판정 결과를 저장하면 "리서치 키워드"가 이 칸에 자동으로 들어갑니다(본 분석 중 AI가 추가로 요청하면, AI가 낸 키워드 코드블럭을 그대로 복사해 이 칸에 붙여넣으세요 — 콤마 구분 그대로).
  - ② '🔍 키워드 리서치 실행'을 누르세요(결과는 STEP 3 복사에 자동으로 들어갑니다). 숫자를 먼저 보고 싶으면 '🔍 검색량·자동완성 조회'.
  - ③ 본 분석 중 AI가 요청한 경우에만 '📋 AI에게 결과 전달'을 눌러 복사한 뒤 같은 대화창에 붙여넣으세요.
- 버튼 동작도 정책뉴스와 같다: 리서치 실행 = 캐시에 저장, 검색량·자동완성 조회 = 따로 조회해 팝업(정책뉴스와 같은 창), AI에게 결과 전달 = "아래는 요청하신 키워드의 실측 결과입니다." + 상세 데이터 복사.
- 정책뉴스에 없는 버튼은 뺀다: "📋 가치판단 재조사 요청 키워드 자동 채우기"(→ 빠른 판정 저장 때 자동 채움으로 대체), "📋 키워드 복사", "🌐 네이버 열기"(1번).
- 줄이 넓어 잘리지 않는지 가상 화면에서 확인한다(지금은 "검색량·자동완성 조회"가 잘림).
