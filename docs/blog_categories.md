# 생활 돈 블로그(nnuiz) 카테고리 정리안 (2026-10-05 제안, 사용자 확인 전)

근거: `docs/homefeed_economy.md` — 블로그 하나를 "생활 돈" 블로그로, 돈 4갈래(받는·내는·빌리는·모으는 돈), 독자 40~60대.

## 새 카테고리 (6개)

| 순서 | 카테고리 | 돈 갈래 | 들어가는 글 |
|---|---|---|---|
| 1 | 지원금·혜택 | 받는 돈 | 지원금·수당·장려금·바우처·환급·보상금, 할인·감면·무료 이용 |
| 2 | 연금·노후 | 받는 돈(노후) | 국민연금·기초연금·퇴직연금, 노후 자금·은퇴 통계, 장기요양·돌봄 비용 |
| 3 | 세금·보험료 | 내는 돈 | 세금·비과세·공제, 건강보험료·본인부담·약값, 공공요금·통행료 |
| 4 | 대출·금리 | 빌리는 돈 | 대출·보증·금리, 채무조정·연체 |
| 5 | 저축·청약 | 모으는 돈 | 청약통장·적금·국채·ISA·자산형성 상품, 가계 자산 통계 |
| 6 | 생활정보 (보관) | — | 돈과 무관한 기존 글. 새 글은 넣지 않는다 |

- 이름은 독자가 바로 알아보는 말로 지었다(갈래 이름 "받는 돈"보다 내용이 보임).
- 연금·노후를 따로 둔 이유: 독자층(40~60대)의 가장 큰 관심사이고, 경제판에서 반응이 좋은 글 대부분이 노후·연금이었다(`eval/samples/homefeed/`).
- 정책뉴스·복지로는 카테고리로 나누지 않는다 — 주제로 섞는다(같은 주제의 검색 글과 홈판 글이 서로 받쳐 줌). 시리즈 구분은 관리 파일·이미지 시그니처로 한다.
- 하위 카테고리는 만들지 않는다(글 226개 규모에서는 나눌수록 비는 칸이 생김). 글이 한 카테고리에 많이 쌓이면 그때 나눈다.
