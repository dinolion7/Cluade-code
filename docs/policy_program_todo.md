# 정책뉴스 프로그램 개선 목록 (Ver10.08 기준)

사용자와 대화하며 모으고, 사용자가 요청하면 한 번에 코드에 반영한다. 반영 전까지 코드는 건드리지 않는다.

## 1. "🗂 2)다중뉴스 사전검토" 탭 삭제 (2026-10-14 요청)

사용하지 않음. 탭과 관련된 것 모두 삭제, 다른 기능에는 영향 없게.

**지울 것**
- 탭 화면 `_build_tab_bulk_review`와 호출(탭 목록 생성부)
- 이 탭 전용 기능: `_copy_prompt_0`(프롬프트0 복사), `_apply_screening_result`(1차 검토 결과 반영), `parse_screening_result`(프롬프트0 표 파싱), `screening_text`·`screening_result_var`
- 프롬프트0 설정: 설정 탭 "프롬프트0 파일명" 칸, `prompt_0_file` 기본값·`PROMPT_FILE_KEYS` 항목(예전 config.json의 값은 읽지 않을 뿐 그대로 둔다)
- 1)뉴스 수집 탭의 안내 줄 "💡 대량 후보 검토(프롬프트0 결과 반영)는 [🗂 2.뉴스대량검토] 탭에서 합니다."
- 맨 위 탭 구성 설명(TAB2 뉴스 대량검토)과 관련 주석 정리

**남길 것 (다른 기능이 씀)**
- `_copy_collect_list_for_prompt0` — 1)뉴스 수집 목록의 Ctrl+C(선택 행 복사)가 이 함수를 쓴다. 이름만 `_copy_collect_list`로 바꾸고 기능은 유지.
- 기사 상태 "검토중" 등 상태 값 — 이력·수집 목록이 같이 쓰므로 그대로.

**주의 — 탭 번호가 하나씩 당겨짐**
- 코드 곳곳에 `self.nb.select(2)`처럼 탭을 **번호로** 이동하는 곳이 있다(분석준비·글작성·인포그래픽·이력관리로 이동 등 약 10곳, 주석에 "대량검토 탭이 끼어들어 +1"). 탭을 지우면 번호가 하나씩 밀려 엉뚱한 탭으로 가게 된다.
- 번호 대신 **탭 화면을 직접 가리켜 이동**하도록 바꾼다(앞으로 탭을 더하거나 빼도 안 틀림).
- 반영 후 탭 이동 버튼·자동 이동을 전부 점검한다.
